# 陪玩计时 · iPhone 手机版

这是一个 **PWA 网页应用**，不是 Windows exe。iPhone 不能直接运行桌面版 `陪玩计时.exe`，但可以把这一版装到主屏幕，像 App 一样打开。

## 能做什么

- 选择游戏、计时、暂停、结束结算
- 结算时填写抽成比例，显示原价 / 抽成 / 实收
- 日账单、月账单、年账单
- 新增、修改游戏和单价
- 关闭页面后数据仍保存在当前 iPhone
- 首次联网打开后，支持离线使用

## 和电脑版的关系

两边是**两份独立数据**，不会自动同步：

- iPhone 上的数据保存在 Safari / 主屏幕应用本地
- 电脑版数据仍保存在电脑
- 需要搬数据时，用页面底部「数据与备份」导出 JSON，再到另一台设备导入

如果以后需要自动同步，需要另做云端后端。

## 部署方法

PWA 必须放在一个 **HTTPS 地址** 上，Safari 才能把它添加到主屏幕并离线缓存。下面任选一种。

### 方法一：GitHub Pages（免费，推荐）

1. 注册 / 登录 GitHub，新建一个仓库。
2. 把本文件夹里的**所有文件**上传到仓库根目录，确保根目录有 `index.html`。
3. 进入仓库 **Settings → Pages**：
   - Source 选 **Deploy from a branch**
   - Branch 选 **main**，目录选 **/(root)**
   - 保存。
4. 等 1–2 分钟，打开 `https://你的用户名.github.io/仓库名/`。
5. 在 iPhone **Safari** 中打开这个网址。
6. 点 Safari 底部「分享」→「添加到主屏幕」。
7. 以后从主屏幕图标打开即可；第一次打开后即使断网也能用。

> 如果放在仓库的子文件夹里，网址会多一层路径，例如 `/仓库名/手机版/`；也可以正常使用，但建议放在根目录，网址更短。

### 方法二：Netlify Drop / Cloudflare Pages

- **Netlify Drop**：打开 Netlify Drop，把整个 `手机版` 文件夹拖进去，得到一个 HTTPS 网址。
- **Cloudflare Pages**：创建项目，上传本文件夹内容，得到 `*.pages.dev` 网址。

拿到网址后，同样用 iPhone Safari 打开 → 分享 → 添加到主屏幕。

### 方法三：电脑局域网临时打开（不用注册账号）

电脑和 iPhone 连同一个 Wi-Fi，在 `手机版` 文件夹执行：

```powershell
python -m http.server 8080
```

然后在 iPhone Safari 打开：

```
http://电脑的局域网IP:8080
```

电脑 IP 可以用 `ipconfig` 查看，例如 `192.168.1.20`。  
这种方式电脑必须一直开着，而且 HTTP 地址不能启用离线缓存；适合临时试用。

## 安装说明

- 必须用 **Safari** 打开，Chrome / 微信内置浏览器不能添加到主屏幕。
- Safari 底部没有工具栏时，点一下屏幕底部或向上轻扫。
- 如果页面内出现「安装到 iPhone 主屏幕」提示，按提示操作即可。
- 添加到主屏幕后，从图标启动会进入全屏独立窗口。

## 数据安全

- 数据只存在这台 iPhone 的浏览器里，不上传服务器。
- 不要随意清除 Safari 网站数据，否则会丢失。
- 换网址、换域名或重装前，先在「数据与备份」里导出 JSON。
- iOS 可能在长期不用后清理网站数据，建议定期导出备份。

## 更新手机版

替换服务器上的文件后，把 `sw.js` 里的 `CACHE` 版本号改一下（例如 `peiwan-mobile-v2`），再关闭重开主屏幕应用即可获取新版本。
